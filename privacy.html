Политика конфиденциальности

Настоящая политика определяет порядок обработки персональных данных пользователей сайта «Таро в деле» (далее — «Сайт»).

1. Какие данные собираются

При заполнении формы на Сайте собираются: имя, телефон и текст запроса, который пользователь указывает по своему желанию. Также Сайт использует сервис Яндекс Метрика, который собирает обезличенную статистику посещений.

2. Цель обработки данных

Данные используются только для связи с пользователем: чтобы ответить на запрос и согласовать расклад или консультацию. Они не передаются третьим лицам, кроме сервисов, технически обеспечивающих доставку заявки (мессенджер Telegram) и сбор статистики (Яндекс Метрика).

3. Хранение и удаление данных

Данные хранятся не дольше, чем это нужно для цели, указанной в п. 2. Пользователь вправе запросить удаление своих данных, написав по контактам, указанным на Сайте.

4. Согласие пользователя

Отправляя форму, пользователь подтверждает согласие на обработку персональных данных в соответствии с Федеральным законом № 152-ФЗ «О персональных данных».
